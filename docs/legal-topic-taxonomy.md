# MootMood — Legal Topic Taxonomy

**Version:** 1.0  
**Date:** November 6, 2026  
**Status:** Approved for MVP Implementation

---

## Overview

This document defines the hierarchical legal topic taxonomy for MootMood. The taxonomy uses a **three-level structure** designed to be intuitive for international law researchers while maintaining precise doctrinal distinctions.

**Structure:**
- **Level 1:** Major Legal Area (6 categories)
- **Level 2:** Doctrine or Principle (20-30 topics)
- **Level 3:** Specific Test or Standard (10-20 subtopics)

## Database Implementation

### Schema Structure

```sql
CREATE TABLE legal_topics (
  id VARCHAR(100) PRIMARY KEY,           -- e.g., 'self-defence'
  parent_id VARCHAR(100) REFERENCES legal_topics(id),
  name VARCHAR(200) NOT NULL,            -- "Self-Defence under Article 51"
  slug VARCHAR(200) NOT NULL UNIQUE,     -- "self-defence"
  description TEXT,
  level INT NOT NULL DEFAULT 0,          -- 0=major area, 1=doctrine, 2=test
  path VARCHAR(500),                     -- "/use-of-force/self-defence"
  display_order INT DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## Terminology Rules

### Critical Distinctions

**DO NOT conflate:**
- Self-Defence ≠ Jus Cogens (different areas)
- Effective Control ≠ Overall Control (different attribution tests)
- State Responsibility ≠ Individual Criminal Responsibility (different legal frameworks)
- Non-Intervention ≠ Prohibition of Use of Force (related but distinct)
- IAC ≠ NIAC (different IHL regimes)

**Use established terminology:**
- "Self-Defence" (not "Self-Defense") — follow UK English for international law
- "Jus Cogens" (not "Jus Cogens Norms" alone) — full term is "Jus Cogens (Peremptory Norms)"
- "Article 51" (not "Article 51 of the UN Charter" every time) — context makes it clear
